This document describes the high-level architecture covering key components, data flows, and integration points.

Architecture

The platform is composed of three primary layers: the API Gateway, the Service Mesh, and the Data Layer. Each layer is independently deployable.

Data Flow

All client requests enter through the API Gateway. Stateful operations persist to PostgreSQL; session data and caches are stored in Redis.
