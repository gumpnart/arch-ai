System Overview

updated: 2026-05-20owner: team-platformtype: sad

High-level architecture of the platform — components, data flows, and integration points.

Architecture

The platform is composed of three primary layers: the API Gateway, the Service Mesh, and the Data Layer.

Data Flow

All client requests enter through the API Gateway, which handles rate limiting and auth delegation, then routes to downstream microservices. PostgreSQL for persistence; Redis for caching and queues.
