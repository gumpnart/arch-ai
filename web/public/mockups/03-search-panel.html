System Overview

This document describes the high-level architecture of the platform, covering key components, data flows, and integration points.

Architecture

The platform is composed of three primary layers: the API Gateway, the Service Mesh, and the Data Layer.

Data Flow

All client requests enter through the API Gateway, which handles rate limiting, authentication delegation to the Auth Service, and routing to downstream microservices.

The Gateway handles rate limiting and auth before forwarding to services.
